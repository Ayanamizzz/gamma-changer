## Gamma Changer 2.6.1

This maintenance release improves foreground application bindings and adds a running-app picker.

- Rebinding an application selects the chosen filter as its default and reuses an existing matching rule.
- Saving an enabled assignment resumes automatic switching after manual adjustments.
- Re-enabling an existing rule resumes switching after saving. Editing an enabled filter's parameters selects it as the application's default when saved.
- Foreground changes reapply the selected filter with a fixed 150 ms coalescing interval.
- Unassigned applications can use a saved default filter for each display, or retain the desktop baseline.
- **Add app...** and **Bind app...** list applications with open or minimized desktop windows. The list shows executable names, window titles, and full paths; supports refresh and manual browsing; and reports process-query errors.
- Existing application rule formats remain readable. Custom unassigned-app defaults are saved atomically in version 3 of the rule file.

### Scope

Matching uses the complete executable path and display identity. Browser tabs and webpage content are not classified; each browser executable shares its application assignment. Games must be bound to the actual game executable rather than its launcher. HDR, exclusive fullscreen, and other color-management software can bypass or overwrite the gamma ramp.

The neutral-gray sidebar, **Common filter / 通用滤镜** naming, single application-settings entry, and **recognition assistance with manual application** are documented as the next design proposal. They are not implemented in this release. The existing automatic-switching and manual-pause controls remain in use.

### Validation

- Windows x64 Release and Debug builds with MSVC `/W4 /WX`.
- Five CTest groups cover core safety, profile migration, calibration transactions, application rules, and native foreground switching. Native dialog and switching tests use a fake display backend.
