## Gamma Changer 2.7.0

Manage gamma and color profiles, their app assignments, and the profile for all other apps in one window.

- Open a profile to tune it and add apps directly on its page. Separate app-management dialogs have been removed.
- Follow apps switches profiles with the foreground app. Opening a profile in the editor shows its adjustments; choosing a profile from the tray turns Follow apps off and keeps that profile active.
- Hold to compare against a neutral response. Reset clears the open profile's adjustments, and Ctrl+Z restores them, including edits that had not auto-saved yet.
- Fix a false step at the midpoint of the tone-curve preview. The display's actual gamma output was unaffected.
- Preserve pending auto-save after a failed comparison preview, stop profile switching if the fallback configuration cannot be saved, and keep keyboard activation of app chips from removing assignments under the mouse pointer.
- Store current adjustments in an editing session and normalize them to the editor's 0.01 steps. Existing off-grid values display at the nearest step without being treated as pending edits.
- Make sample screenshots repeatable and expand regression coverage for editing and foreground-app decisions.

### Validation

- Seven automated test groups cover core safety, profile migration, calibration transactions, app rules, app runtime, editing sessions, and native foreground switching.
- Display-write tests use a fake backend. Physical monitor behavior, sleep/resume, and hot-plug behavior have not been manually verified for this release.

Download the portable ZIP, extract it, and run `gamma_changer_gui.exe`. Existing profiles remain in `%LOCALAPPDATA%\GammaChangerCpp\`.
