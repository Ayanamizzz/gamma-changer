## Gamma Changer 2.6.2

This maintenance release fixes calibration precision and profile-file handling, and reorganizes the application runtime, persistence, and UI code.

- Round slider values to the nearest 0.01 step so loading settings such as 1.15 does not turn them into 1.14.
- Track active previews by stable display identity so a monitor can cancel its preview after Windows renumbers display devices.
- Treat an existing but unreadable `profiles.v1` as unavailable rather than missing, preventing legacy migration from overwriting it.
- Extract automatic application switching into a runtime engine and route desktop-ramp capture and restoration through the calibration controller.
- Consolidate atomic file writes, adjustment-control bindings, and saved-state UI updates. Profile changes made from the tray now update the save-button label consistently.
- Split the build into core and UI libraries and add a dedicated runtime regression test group.

### Validation

- Windows x64 Release and Debug builds with MSVC `/W4 /WX`.
- Six CTest groups cover core safety, profile migration, calibration transactions, application rules, application runtime, and native foreground switching.
- Display-write tests use a fake backend; they do not change the monitor's gamma ramp.

Download the portable ZIP, extract it, and run `gamma_changer_gui.exe`. Existing profiles remain in `%LOCALAPPDATA%\GammaChangerCpp\`.
